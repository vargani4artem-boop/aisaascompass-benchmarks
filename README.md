# AI SaaS Compass — Open Benchmark Datasets & 5-Pillar Scorecard Verifier

Official public dataset and formula verification repository for **[AI SaaS Compass](https://aisaascompass.com)** (https://aisaascompass.com/datasets/).

## 1. Deterministic 5-Pillar Product Scoring Formula
Every software platform evaluated on AI SaaS Compass is scored individually from **1.0 to 5.0** across 5 weighted engineering and commercial pillars:

`	ext
Overall Score = round((0.30 * Reliability) + (0.25 * Integration) + (0.20 * Security) + (0.15 * UX_Speed) + (0.10 * TCO_Value), 1)
`

- **Pillar 1: Output Quality & Autonomous Reliability (30% Weight)**
- **Pillar 2: Integration & API Ecosystem Depth (25% Weight)**
- **Pillar 3: Security, SOC2 & Enterprise Governance (20% Weight)**
- **Pillar 4: UX, Latency & Onboarding Speed (15% Weight)**
- **Pillar 5: Total Cost of Ownership (TCO) & Value (10% Weight)**

## 2. How to Run the Formula Verifier (scorecard_verifier.py)
`ash
python datasets/scorecard_verifier.py
# Output: Verified 206 product scorecards across 54 benchmark datasets. Formula mismatches: 0
`
