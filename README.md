- **65 CSV comparison datasets** (`*-benchmark.csv`) backing every head-to-head software benchmark and interactive calculator on AI SaaS Compass.
- **Master 5-Pillar Scorecard Table** (`all-tools-5pillar-scorecards.csv`) covering all **55 evaluated software platforms**.
- **Zero-Dependency Python Verification Script** (`scorecard_verifier.py`) that recomputes the weighted formula across all platforms and asserts `0` discrepancies.

## 5-Pillar Weighted Scoring Formula

```
Overall Score = 0.30 * Reliability + 0.25 * Integration + 0.20 * Security + 0.15 * UX + 0.10 * TCO_Value
```
